Our devops course (COMP3104), It's about how code gets from a developer's laptor inot a running application, using automation and shared tools instead of doing it all by hand.

The course started with Git. I learned git init, how to commit changes, and how branches and pull requests work when a few people are on the same project. This assignment is mostly the same thing with more people.

The biggest topic so far is GitHub Actions. A workflow is just a YAML file in the .github/workflows folder, and it runs on its own when something happens, like a push. It runs on a hosted machine (ubuntu-latest for us), and the Actions tab shows whether the run passed or failed.
